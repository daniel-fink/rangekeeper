# Contributor instructions

Read [the documentation index](docs/README.md),
[architecture](docs/concepts/architecture.md) and
[contributing guide](docs/contributing/README.md) before changing this repository.
Apply [documentation upkeep](docs/contributing/documentation.md) with each change.
Follow ASD-STE100 principles, with exceptions for clarity and technical accuracy.

Start new `feature/<name>` branches from `develop`, integrate reviewed work into `develop`,
and reserve `main` for releases. All chats share the branch, files and index;
coordinate branch changes, staging, commits, merges and shared environments.
Inspect Git state before edits and preserve unrelated work and ignored evidence.
Commit, push and publish only within the user's requested scope.

Preserve the existing `codex/walkthrough-acausal` branch and `gh-pages` publication
boundary. Follow the [walkthrough procedure](docs/guides/walkthroughs.md#branches-and-publication).
Repository consolidation does not authorise walkthrough publication or close
Bundle, host, UI or release acceptance. Keep verification and delivery distinct.
