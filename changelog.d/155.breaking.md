Execution errors are renamed so that each name ends in `Error`: `UnsupportedProblem` and `UnsupportedExpression` are now `UnsupportedError`, `BackendUnavailable` is `BackendUnavailableError` and `AttemptDeadline` is `AttemptDeadlineError`. `HierarchyError.code` is a `hierarchy.*` code, for example `hierarchy.multiple_parents`, and its message no longer starts with the code. `BoundaryError` and `ValueEncodingError` are removed; catch `RangekeeperError` or `EncodingError` instead.
