Entity handles take equations as text: `project.equations("total_cost = land_cost + works_cost", "noi = coverage * debt_service")`. Text is the Python form with `=` for equality, `and`, `or` and `not`, quantity literals such as `2 years` and `7 % pa`, `NEVER`, and `code.key` for a value of another entity; it makes the same Expression records as the record constructors. Text that does not make an equation raises the new `rk.errors.EquationError`, which marks the part that fails (`text`, `start`, `end`, `suggestions`) and has a code, such as the new `EQUATION_SYNTAX` and `EQUATION_FUNCTION`. Equation functions and Flow methods (`rx.max`, `x.at(on=)`) parse but are not available yet (#278).
The equation text of diagnostics and errors, such as `UnsupportedError.equation`, now uses the same spelling (`and`, `or`, `not`, `True`, `False`, `NEVER`) and writes each magnitude in full.
