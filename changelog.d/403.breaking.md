`rk.duration.containing_period(*, on=, grid=)` takes a calendar grid in place of `frequency=`, `week_start=`, `year_start_month=` and `origin=`: `DayGrid()`, `WeekGrid(starts=calendar.Day.MONDAY)`, `MonthGrid(frequency=, year_starts=calendar.Month.JANUARY)` for months, quarters, half-years and years, or `MultiYearGrid(frequency=, origin=)` for bienniums, quinquenniums and decades. Each grid takes only the choices that apply to it and checks them when it is made; a week grid no longer accepts an origin that it then ignored. `rk.duration.Grid` is the union of the four types.
