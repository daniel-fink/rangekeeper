`rangekeeper.execution.solve(specification, resolver, config=)` runs every execution stage and writes nothing; `rangekeeper.execution.execute(specification, store, config=)` solves, then publishes the Specification, each output and then each Run. Both return an `Outcome` with `run`, `outputs` and, for a batch, `cases`. `Executor` is removed: replace `Executor(store, config=c).execute(s)` with `execute(s, store, config=c).run`. `execute` validates each Run once, at `store.put`, and writes nothing when solving raises.
