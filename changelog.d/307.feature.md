`rk.execution.DecisionResult` names the result of one check of a decision rule (`DECIDED`, `NOT_MET`, `SKIPPED`, `OTHERWISE`). The traversal `Direction` enum is public as `rk.model.Direction`. `rk.execution.Status` now lives in `execution/statuses.py`: each row of `FAILURES` gives the `Status` and the diagnostic code of one expected error, so both change in one table.
