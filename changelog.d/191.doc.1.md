The API reference of the docs site has a page for each public module: the packages of the API snapshot, such as `rangekeeper.model.system`, `rangekeeper.execution.backends` and `rangekeeper.specification.rule`, and each module with its own `__all__` that exports more names, such as `rangekeeper.model.system.table`.
