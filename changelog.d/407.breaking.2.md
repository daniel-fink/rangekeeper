`shared`, `schema`, `money`, `finance` and `market.dynamics` raise Rangekeeper errors with codes. `Table.row`, `Table.column` and `Record.has_field` raise `MissingReferenceError` for an unknown key; it is a `LookupError`, not a `KeyError`, so change an `except KeyError` to `except LookupError` or `rk.errors.MissingReferenceError`. `Record.from_data` raises `ValidationError` with `Code.STRUCTURE_JSON` for data that is not JSON, such as a `date` value, where it raised `TypeError`; `validate()` reports the same Issue. `money.round` with an unknown mode raises `ContractError`, and with a code that has no minor unit and no `places`, `UnitError`. Empty text in a name or code, an invalid extension name, a JSON pointer that is not canonical, `payment` with a frequency that has no unit, a rate of -100 % pa or less and invalid market kernel parameters raise `ContractError`; a non-finite currency amount and a volatility overflow raise `NumericalError`. Each of these is a `ValueError`, so `except ValueError` still works.
