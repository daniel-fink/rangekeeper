Declare a rule as a query: `rk.specification.Window(earliest=, latest=, periods=None)`, `where(condition=)` and `first(otherwise=, then=None)`, fixed with `fix(key=rule)`. `Specification.rules` gives the rules by key, with the values that they read. A condition writes equality with `==`; equation text keeps `=`. `rk.execution.solve` does not run these rules yet: a case with rules ends as `unsupported`.
