Date values: `ValueKind.DATE` Values record a calendar date (`date`) or `rk.duration.NEVER` (`never`), and a date Expression literal records a calendar date (`date`) or NEVER (`never`) in the same shape (`rangekeeper.model.expression.authoring.date_literal`). Equations compare dates and add or subtract whole calendar lengths, such as `1 year`; NEVER equals NEVER and is later than every date. `rk.duration.shift(on, by=)` does the same arithmetic in Python. The stored formats stay at 1.0.0 and gain these optional fields; 0.x documents need no conversion for them.
