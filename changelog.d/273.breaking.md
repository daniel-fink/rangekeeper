The Flow and Stream API takes keyword arguments (D14): write `Stream(flows={...})`, `flow.trim(span=...)`, `flow.resample(periods=..., method=...)` and `stream.select("a", "b")` (names as separate arguments). `ResamplingMethod` is now `ResampleMethod`; the codemod applies the rename. A Stream's default join is `AlignmentJoin.UNION`, and aggregation treats a coordinate that a line does not have as no movement: only unresolved amounts follow `missing`. Pass `join=AlignmentJoin.EXACT` to require identical coordinates.
