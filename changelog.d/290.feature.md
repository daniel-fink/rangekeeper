`Specification.fix` takes Quantity text (`land_cost="20e6 AUD"`) and a bare number for a ratio (`coverage=1.25`) as well as Quantities. `Specification.roles` returns a Table with the role of each value (`rk.specification.Role`: `FIXED`, `FREE` or `DECIDED`) and its fixed Quantity, and `Specification.model_id` gives the pinned Model revision.
