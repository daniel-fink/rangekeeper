`rk.flow` raises Rangekeeper errors with codes. An unresolved or non-finite amount raises `NumericalError` (was `ValueError`); `Flow.convert` between incompatible units raises `UnitError`; coordinates that do not align raise `rk.duration.AlignmentError` with the new codes `Code.ALIGNMENT_MIXED`, `ALIGNMENT_DIFFER`, `ALIGNMENT_DUPLICATE` and `ALIGNMENT_GAP`, or with `ALIGNMENT_CROSSES` and `ALIGNMENT_PARTIAL`; other wrong values raise `ContractError`. These subclass `ValueError`, so `except ValueError` still works. `Stream.select` and `Stream.select_values` raise `MissingReferenceError` (a `LookupError`, not a `KeyError`) for a name or Value ID that is not in the Stream, and `Stream.merge` raises `IdentityConflictError` or `RevisionConflictError`. `Stream.from_values` with a Value that is not a Flow raises `ContractError` with `Code.REFERENCE_KIND`.
