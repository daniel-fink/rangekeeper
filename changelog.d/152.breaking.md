An underdetermined solve has no output by default (ADR-016): its Run records the new solution status `underdetermined`, its diagnostic names the free unknowns (with their keys in `values.unknowns`), `execute` stores no output Model and `outcome["key"]` raises the error of `raise_for_status()`. `ExecutionConfig(allow_underdetermined=True)` publishes the verified candidate; the solution stays `underdetermined`. Runs that 1.0.0a2 wrote still read as `UNDERDETERMINED`.
