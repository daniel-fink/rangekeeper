The Run record `rk.run.Status` is now `rk.run.RunStatus`, so that `rk.execution.Status` is the one public `Status`; stored Runs do not change, and the codemod applies the rename. `Termination.LIMIT` is now `Termination.LIMITED` (`"limited"`) and `Termination.ERROR` is now `Termination.FAILED` (`"failed"`), the words of `Status` for the same ideas. New Runs record the new words in the `solver_termination` diagnostic; `Outcome.evidence` still reads `limit` and `error` from an older Run.
