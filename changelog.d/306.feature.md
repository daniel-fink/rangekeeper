Add `Specification.across(paths=, series=None)`: a batch Specification with one case for each path of a `rangekeeper.market.Paths` document. Each path series fixes the Model value with the same key, and `series=` maps a value whose key differs. A case refers to its path by UUID and key, without copying the amounts, and its composition expands the path into assignments. `Run.paths` pins the Paths that the cases used; stores, `execute` and Bundles carry them. `Table.head(count=5)` returns the first rows of a Table.
