Specification parameters for rule triggers: `spec.parameters(start_trigger=1.05)` declares a named value that a condition or a window bound reads by key, and `fix` and `cases` change it without a Model revision. `across` of a batch now makes one case for each pair of a case and a path, and each Run records its path key in `run.path_key`, which paired comparisons read. `spec.rules[key].triggers` holds the parameters that a rule reads, so a reused rule no longer brings the fixed Model values that it reads.
