The public stage records drop unused fields and use the glossary words: `Analysis.rank` is now `Analysis.equality_rank` and `Analysis.free` is removed (read `undetermined`); `Verification.accepted` is now `Verification.passed`; `Validation.scope` is private. `assemble(specification, report, *, id, output)` and `assemble_batch(specification, cases)` no longer validate: validate the Run with `rk.run.validate(outcome.run, resolver=rk.execution.Overlay(resolver, models=outcome.outputs))`, where `rk.execution.Overlay` is now public. `rk.run.Prerequisites` and the `prerequisites` parameter of `rk.run.validate` are removed. `Cases.compositions` holds only compositions; a leaf that fails to compose is in `Cases.failures`.
