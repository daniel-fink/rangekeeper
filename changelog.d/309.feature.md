Equations in Python: `import rangekeeper.expressions as rx`. Value handles and `rx.Term` take Python's operators (`==`, `>=`, `&`, `|`, `~` and the arithmetic operators) and the Flow methods `at`, `total` and `shift`, and `project.equations(...)` takes the result as it takes text: `project.equations(noi == coverage * debt_service)`. One registry of equation functions (`rx.functions`) gives `rx.max(a, b)`, the equation text functions and methods, and the function table of the expressions reference; text and `rx` make the same records, and each call is checked when it is written, with suggestions. A Model stores the Function record of each equation function that its equations call.
