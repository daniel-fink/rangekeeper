Execution solves piecewise equations: a call of `rx.max` or `rx.min` (a Function with that code in the Model's definitions) that reads a free value, such as the equity-first cascade `loan_principal = rx.max(0 AUD, funding_need - equity)`. The solve picks the active side of each call, solves the affine problem, checks the sides at its solution and verifies the original equations. When no sides hold, the Outcome is `FAILED` with the new code `active_side`, and `raise_for_status()` raises `NumericalError`.
