`rangekeeper.execution.compare(..., baseline=)` pairs two batches across market paths by path: by the Paths that each case's Run pins and the path key. A batch of cases, each across the paths, pairs with one batch across the same paths, and `by_case` gives the statistics of each case. Batches across other Paths raise `ContractError` with the new code `comparison.paths`, where they paired by case key before; batches with other path keys raise `comparison.cases`.
