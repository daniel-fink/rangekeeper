`rk.duration` has one way to build Periods and Spans. `make_period` is removed: use `Period(start=, end=)`. `make_periods` is removed: use `Periods(start=, frequency=, count=)`, which returns a `Periods`, not a tuple. `periods_between` is removed: use `Span(start=, end=).periods(frequency=, include_partial=)`. `Span.from_duration` is removed: use `Span(start=, length="10 years", name=)`. `Span.periods(month_roll=)` defaults to `MonthRoll.PRESERVE_END` instead of `None`.
