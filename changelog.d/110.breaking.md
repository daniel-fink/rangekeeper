Validation runs in tiers (ADR-011). Typed record constructors and `replace` run generated node checks of the one record, not jsonschema; jsonschema runs for untrusted input only: `from_data`, `from_json`, the JSON and YAML codecs and `DirectoryStore` reads. Semantic validation stays at Model, Specification and Run construction and before execution. A typed constructor that rejects a field now reports `structure.value`, `structure.required` or `structure.rule` with the field path, instead of the jsonschema keyword code. Building a Flow is about 5 times faster.
