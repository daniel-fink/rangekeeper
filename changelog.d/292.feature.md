`Specification.cases(cases={key: {value: input}})` makes a batch with one named case for each key; each case fixes its values over the base's, and `Specification.case(key=)` returns one. A batch keeps its cases, so `solve` resolves them and `execute` stores them before the batch. A batch `Outcome` gives `case(key=)` and `table(*keys)` (one row for each case, with its status), each Outcome has a `key`, and `outcome.stream(*keys)` returns a Stream of solved Flows. `Specification.model` and `Specification.resolver` return the Model and resolver that the facade keeps.
