`rangekeeper.model.Filter` is a declarative selection, stored as data: a Classification with its sub-types, Label criteria, unit-aware Value tests (`ValueTest` with a `ValueRelation`: equal, not equal, less, less or equal, greater, greater or equal, between, present and missing). `View.match(condition=)` returns a `Match` of the Entities that pass, fail or have a missing tested value; `View.where(condition=)` keeps the Entities that pass. A missing value never passes a test and never counts as zero.
