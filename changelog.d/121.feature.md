`rangekeeper.model.Filter` is a declarative selection, stored as data: a Classification with its sub-types, Label criteria, unit-aware Value tests (`ValueTest` with a `ValueRelation`: equal, not equal, less than, less than or equal, greater than, greater than or equal, between, present and missing). `View.match(condition=)` returns a `Match` of the Entities that pass, fail or are undecided because a tested value is missing; `View.where(condition=)` keeps the Entities that pass. A missing value never passes a test and never counts as zero.
