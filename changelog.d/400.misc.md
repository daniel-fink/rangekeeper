CI checks the structure of `src/rangekeeper`: ruff limits function complexity, arguments, branches, returns and statements, requires imports at the top of the module and type hints on each function, and mypy is strict for the root module, `rangekeeper.errors` and `rangekeeper.money`. A per-file baseline lists the older code that does not pass yet, and a mypy override lists the packages that are not yet strict; `tools/ci/check_baseline.py` fails when a pull request adds to either.
