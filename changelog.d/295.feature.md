`rk.io.save(document=, path=)` writes one document to a JSON file with the documents that it depends on, and `rk.io.load(path=)` reads it back with no kind. A loaded Specification keeps its Model and the other documents as its resolver, so `rk.execution.solve` resolves it. `save` makes missing folders, never replaces a file and returns the path when the file holds the same document already.
