`Outcome.raise_for_status()` reads the error class from the same `FAILURES` row as the status, so the error keeps its code and fields: a deadline raises `AttemptDeadlineError`, an invalid Specification raises `ValidationError` with every issue of the attempt (the Run's `specification_invalid` diagnostic now records them in `values.issues`), and a failure code that no row names gives `Status.FAILED`, not `UNSUPPORTED`. `OutcomeError.status` is typed `Status`, and `OutcomeError` survives `pickle`.
