Value types keep their local rules from construction: a Period starts before it ends; a Movement has a date or a period; a Flow has unique Movement IDs and ordered, unmixed, non-overlapping coordinates; a Distribution has valid parameters. Construction, `replace` and `from_data` raise `ValidationError` (code `invariant.<kind>`) when a rule fails, so an invalid value can no longer exist until a later `.check()`. `Period.check()` and `Span.check()` are removed. `Flow.check()` now checks only the units and, with `resolved=True`, the numbers; `Distribution.check()` checks only the units.
