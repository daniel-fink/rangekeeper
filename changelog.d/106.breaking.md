Generated records contain data only. `rangekeeper.schema.behaviors` is removed: `Flow` and `Movement` are owner subclasses in `rangekeeper.flow`, `Period` and `Span` in `rangekeeper.duration`, and `Distribution` (still public as `rangekeeper.model.Distribution`) in `rangekeeper.profile`. Construction of a generated record, `from_data` and nested decoding return the owner class, so existing code keeps its methods. Import `MissingValueHandling` from `rangekeeper.flow`. `replace` returns `Self`.
