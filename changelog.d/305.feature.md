Entity handles group equations in named Formulations: `project.add_formulation(name="Funding")` returns a `FormulationHandle` whose `equations(...)` adds to it, and `project.formulation(name=)` finds it in a later draft. A named Formulation is a child of the entity's default Formulation. The `constraint_residual` diagnostic names the Formulation of each equation in `values["formulation"]`.
