`rk.execution.replay(run=, store=, config=None)` solves the Specification of a stored Run again and compares each case's status, outputs and values with the stored ones; the `Replay` that it returns holds the stored and the new Outcome, one `replay_mismatch` diagnostic for each difference, and `raise_for_status()`. `store.find_runs(specification=name)` returns the Runs of the Specifications with that name, in the order that they finished, so `[-1]` is the latest. `execute` now also puts the input Model, includes and cases that the store does not hold, so a store can start empty.
