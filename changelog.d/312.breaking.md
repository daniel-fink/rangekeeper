A Run `Diagnostic` has an optional `values` field: one JSON object of the named inputs and evidence of the finding. A `settings_adjusted` diagnostic must name its settings in `values.settings`; Run validation no longer searches the message for them. The `solver_termination` and `solver_scaling` diagnostics record their solver evidence in `values`, not as JSON text in `message`. Read `values`; a reader older than this release rejects a Run that has the field. A backend `Result.evidence` must be JSON.
