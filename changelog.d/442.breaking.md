An underdetermined solve is `Status.UNDERDETERMINED` with or without bounds, so `raise_for_status()` raises `OutcomeError`; before, any bound in the problem made it `FEASIBLE`. The diagnostic code is `uniqueness_not_assessed` only when a bound reads a free unknown, else `underdetermined`. `Analysis.has_bounds` is replaced by `Analysis.bounded`, the undetermined unknowns that an inequality row reads.
