Every public enum is a `StrEnum`: a member equals its word and `str()` gives the word, for example `rk.model.Direction.INCOMING == "incoming"` and `str(rk.duration.Frequency.MONTH) == "month"`. This covers the enums that the schema generates and the hand-written `Frequency`, `MonthRoll`, `PeriodTiming`, `DayCount`, `MissingValueHandling`, `AlignmentJoin`, `AggregationMethod`, `ResampleMethod`, `MeanWeighting`, `Contributor`, `Reducer`, `CoverageStatus` and `HierarchyKind`. Code that compared a member with a string, or formatted a member with `str()` or an f-string, now sees the word. The generated enums carry their LinkML descriptions as docstrings, so the API reference shows them.
