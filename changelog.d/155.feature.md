Every error that Rangekeeper raises subclasses `rangekeeper.errors.RangekeeperError` and has a `code` from `rangekeeper.errors.Code`. Each keeps the built-in base that callers catch today, for example `ValueError`. `rangekeeper.errors` exports the base and the errors that several packages raise, such as `ValidationError`, `MissingReferenceError`, `UnitError` and `UnsupportedError`; an error of one package, such as `HierarchyError`, stays in that package.
